Published v0.7.0: Extensions contains 20 optional entries: six native workbenches and fourteen guides or links with explicit integration levels. It replaces the Publish destination in the six-part layout: Home, Inspect, Network, Extensions, Files and Settings. Older v0.6.1 binaries retain their earlier layout. Native-client, account and independently promoted package acceptance remain separate from release availability.

Start with what you need

Open Extensions at /extensions, search for a task or tool, and select one entry. Pin the entries you use to keep them close in this library. Pins and manual setup-platform choices store only catalog and platform IDs in this browser, without addresses, credentials, pairing data or results.

Opening the catalog does not inspect tools or load every detail pack. The selected entry’s details load when you open it. Choose Check this host for one local availability observation. It checks this process’s PATH and reviewed fixed locations without executing the selected tool. aria2 may also read and verify an existing cached bundle checksum. Detection does not start a process, scan, capture, sign-in flow, model download or service. Cancelling a slow check detaches the browser; an OS filesystem lookup already waiting may still finish.

Setup applies to the machine running ProtoPeek, which may differ from the machine displaying your browser. A remote server or container needs its own accessible tools. Guidance uses the host operating system and points to official installation instructions.

Every example endpoint is an unsent draft. Verify the actual host port before Send; a forwarded, guest or container port can differ from its host mapping. Never publish the Caddy admin port or the Ollama/LM Studio model-server ports. Caddy’s example reads GET /reverse_proxy/upstreams, not the full /config/ document. The guide does not create a reverse proxy or change its configuration. Use the existing reviewed publishing workbench for supported exposure operations, with its explicit audience and native acceptance requirements.

For AI clients, pair the local workbench through 127.0.0.1, choose the client format, and merge the generated fragment into its named configuration file. Do not replace unrelated settings or paste a pairing token into chat. Formats were checked against vendor docs on 23 October 2026; actual installed-client and account acceptance remain separate.

ChatGPT web does not read local Codex configuration, and this library supplies no direct web stdio connector, hosted account or public MCP relay. Its fixed companion prompt contains no addresses, headers or results. The Codex CLI entry covers the separate local stdio workflow; ChatGPT web does not read that configuration. Ollama/LM Studio installation, model download/loading and server startup are separate native actions; no model is downloaded by opening this library.

Read the status accurately

StatusMeaning
Not checkedNo availability observation was requested for this entry.
DetectedAn executable was found in a supported location. It has not been run by this check.
IncludedThis build supplies the tool as a fallback; another installation may take priority.
Not foundThe named CLI was not found on this process’s PATH or the listed locations; this is not proof the application is uninstalled.
UnavailableDetection could not be completed on this host. Read the reported reason.

Detected does not mean ready. Tailscale can still need sign-in, a service can be stopped, and dumpcap can lack capture permission. Open the relevant workbench for its actual capabilities and observations. Installation detection and operational evidence remain separate.

Checks describe the CLI and locations searched. If you installed a tool after starting ProtoPeek, restart ProtoPeek so its process receives the updated PATH, then check again. LM Studio checks the lms CLI rather than declaring whether its desktop app is installed. ChatGPT web is an external link and has no executable check.

Slow filesystem lookups share two slots, including the legacy six-tool API. A busy host check returns HTTP 429 with retry guidance. Cancel stops waiting (499); a lookup already inside the OS retains its slot until it returns. Static catalog metadata and ChatGPT’s external guidance remain available without filesystem slots. On macOS, native workbenches retain their own supported executable locations; keeping Homebrew’s bin directory on ProtoPeek’s PATH lets the native tool and its availability check use the same command.

Tailscale and Cloudflare Tunnel

Install Tailscale using its official download page and the Windows, macOS, or Linux instructions. Complete sign-in through the installed Tailscale client, then open its ProtoPeek workbench and choose Inspect Tailscale. ProtoPeek uses the installed client; it does not provide the private-network service itself.

Use Cloudflare's cloudflared downloads for the tunnel connector. Its ProtoPeek workbench inspects the local host and canonical service. It does not create an account, sign in or install the connector. v0.7.0 configuration writes require the supported user-owned canonical file, a fresh revision and explicit review. See the Cloudflare Tunnel guide for supported controls and configuration authority. Wrangler and Docker availability are diagnostic details, not additional working adapters.

The Tailscale workbench retains its separate Headscale HTTPS login-server flow; this library does not administer a Headscale server. Use NetBird’s official installation guide for its native client and daemon, complete sign-in there, then inspect it through the NetBird workbench. Temporary Serve/Funnel/Quick Tunnel sessions have their own reviewed audience and lifecycle controls. v0.7.0 foreground publishing uses its guarded Windows/Linux path; macOS foreground publishing remains unavailable.

Capture setup

Install Wireshark, which supplies the dumpcap capture utility. ProtoPeek uses dumpcap for bounded local captures; Wireshark remains useful for deeper analysis of original files.

  • Windows: live capture needs Npcap. The Wireshark installer includes Npcap setup. Capture access can still depend on the driver's permission settings.
  • macOS: follow Wireshark's ChmodBPF installation instructions for capture access, and make dumpcap accessible to the ProtoPeek host.
  • Linux: use the distribution's Wireshark packages and the official capture permission guidance.

ProtoPeek does not install drivers or change capture permissions. After setup, open the capture workbench to inspect available interfaces. An explicit Start capture action begins a bounded run. It observes traffic visible to the selected interface, not every packet on the network. Live capture acceptance still depends on the host's driver and permission setup.

Nmap and aria2

Use the official Nmap download and installation guide, then open its workbench and review the target and ports. ProtoPeek supports bounded TCP connect and light service detection. These modes use ordinary TCP sockets; executable detection does not run a scan. See Nmap scope and evidence limits.

The Downloader uses aria2. Official downloads are linked from the aria2 release page. The engine can be configured, found on PATH, or supplied as a fallback by the build. Check the card and Downloader's engine details before installing another copy. Detection does not start the engine or queue a transfer.

The existing Windows x64 aria2 bundle is the explicit exception to separately installed tools. This library adds no new vendor executables, SDKs or model bundles for users who do not use them.

What stays in the core

HTTP and gRPC inspection, this-device evidence, Nearby devices, built-in TCP port checks, supported native hop tracing, saved network maps and bounded capture-file reading work without these optional tools. Opening a PCAP/PCAPNG file stays under Network → Packets and does not require Wireshark, dumpcap or Npcap.

Headscale administration, integrated sign-in/elevation and automatic tool installation remain outside these adapters. Existing AI agent setup remains under Settings; a setup entry does not require a new ProtoPeek plugin or background service.
