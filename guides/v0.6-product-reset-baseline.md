# v0.6 product-reset baseline

Captured on 2026-09-02 before production redesign edits. This record is the Phase 0 comparison
point for the selected Option 1 - Session Workbench direction.

## Source and environment

- Repository: `b01c2ce` (`docs: capture ProtoPeek suite reset roadmap`), clean before this baseline
  documentation was added.
- Host: Windows, `windows/amd64`.
- Go: `go1.27.0`.
- `package.json` package manager declaration: Bun `1.3.10`.
- Bun executable used for the baseline: `1.4.0`.
- Frontend build: Vite `8.0.3`.

The Bun executable mismatch is recorded rather than hidden. It did not prevent the baseline test or
build from passing.

Observed desktop baseline:

- a tall website-like global header and left rail compete with route content;
- eight primary areas plus Roadmap expose the old organization;
- repeated rounded cards dominate the canvas; and
- route/session/context/status ownership is not expressed by one workbench shell.

Observed narrow baseline:

- the rail becomes a top navigation region but content still reads like a compressed landing page;
- heading, body copy, and list content clip at the right edge; and
- permanent shell responsibilities are still distributed across route-local chrome.

## Evidence limitations

This Phase 0 capture verifies the Windows browser build and deterministic local frontend states. It
does not claim Linux or macOS real-host behavior, live gRPC/HTTP targets, Cloudflare installation,
public identity, local-network membership, or filesystem permissions that were not present in the
capture environment. Cross-platform and capability-specific claims require their own later evidence.
