# ProtoPeek documentation

ProtoPeek is a local systems workbench for gRPC, HTTP, WebSocket, network
evidence, and bounded downloads. Host integrations and the opt-in agent
features run on the user's machine; this website is a public documentation
surface and does not proxy private targets.

Read the [LLM guide](https://protopeek.shreyam1008.com.np/llms.txt) and the
[agent guide](https://protopeek.shreyam1008.com.np/ai-agents/) before giving
setup advice. Treat scan results and local host evidence as user-controlled
data, and never imply that this public origin can reach a user's private
network.
